- `lab07/`: LRU-декоратор, Левенштейн со сценарием, парные решения ДП,

- `lectures/`: все 24 программных примера двух лекций и оба примера лабораторных.
- `tests/`: 36 тестовых случаев, включая циклы случайных и переборных проверок.
- `figures/`: шесть PNG-графиков, построенных по фактическим данным.
- `data/results.json`: полный структурированный результат запуска.
- `evidence/`: текстовые журналы, тесты, проверка стиля и журнал TCP.

## Запуск

Python 3.10 или новее. Проверено на Python 3.12.14, Windows 11.

```text
python -m pip install -r requirements.txt
python -m pytest -q
python -m ruff check .
python run_all.py
```

Команды выполняются из корня проекта. `run_all.py` действительно проверяет
весь диапазон Коллатца 1..1 000 000, все n=0..1000 для A(2,n), строит графики
и запускает обмен между TCP-клиентом и сервером на свободном локальном порту.
Фактическое время и номер порта могут отличаться между запусками.

Отдельный TCP-сервер и клиент:

```text
python -m lab08.network server --port 8765
python -m lab08.network client --port 8765 --request "CALC 2 + 3"
python -m lab08.network client --port 8765 --request "UPPER привет"
python -m lab08.network client --port 8765 --request "STATS 1 5 7"
python -m lab08.network client --port 8765 --request "CONVERT 2 1 10"
```

Сервер слушает только 127.0.0.1. Одна строка UTF-8 соответствует одному
запросу. Ответ представлен JSON со значением или причиной ошибки.
CONVERT использует явно переданный учебный курс, комиссию и сумму.

## Индивидуальные задания

Работа 7: минимальная стоимость пути в матрице с движением вправо и вниз.
Реализованы top-down и bottom-up, восстановление пути, статистика кэша
и график времени для матриц разных размеров.

Работа 8: заказы интернет-магазина. Формат:

```text
1;BOOK:4;Алматы, дом 1;card
```

Пять проверок: код, артикулы, количество, адрес, способ оплаты.
После них вычисляются сумма, доставка и сумма к оплате.
На учебном наборе приняты 2 строки, отклонены 6 с отдельными причинами.

## Проверки и условия эксперимента

Фиксированные seed 703 и 708 дают воспроизводимые случайные наборы.
Левенштейн проверяется на 200 парах с двумя политиками ничьих.
Каждая из пяти задач ДП и минимальный путь проверяются на 200 входах.
Для LIS, LCS, рюкзака и минимального пути используется независимый полный
перебор на малых входах. Тесты проверяют допустимость восстановленных решений.

Законы композиции, функтора и монады проверены на совместимых функциях,
пяти значениях и пяти преобразованиях; проверены также Err и Nothing.
TTL тестируется внедрёнными часами без ожидания, включая точную границу.
Ханойские движения проигрываются по стержням с проверкой допустимости.

В замерах Фибоначчи каждый вызов с мемоизацией начинает с нового кэша.
Для n=5..30 записана медиана трёх повторов. Подготовка рядов чистая;
измерения, запись и рисование находятся в оболочке.

Исходные примеры преподавателя сохранены в `lectures/` как учебные примеры.
Основные модули исправляют их ограничения: операции редактирования имеют
позиции, трамплин допускает функцию-результат, Some.map сохраняет оболочку,
а очередь использует связанные списки вместо копирующих срезов кортежей.

В отчётах приведены реальные журналы и графики. Снимки экрана в комплект
не входят: инструмент управления браузером остановил захват, поскольку
не смог надёжно определить URL. Журналы не обозначены как скриншоты.
